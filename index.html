Build cards

Paste words separated by commas or new lines, or paste a JSON list.

JSON format 
[
  "candid",
  {
    "word": "nuance",
    "pos": "noun",
    "phonetic": "/ˈnuː.ɑːns/",
    "definition": "A subtle difference.",
    "definitionZh": "細微差別",
    "examples": ["First sentence.", {"text": "Second.", "en": "English", "zh": "繁體中文"}]
  }
]

Every field except word is optional. Missing parts are filled from the dictionary, the built-in word list, or an editable template.

    Account & multiple devices

    Not signed in.

    Sync starts anonymously. To use the same data on another device, link an email here, then sign in with it on that device.

    Setup help

    1. In the Firebase console create a project and add a Web app. Copy its firebaseConfig above.

    2. Authentication > Sign-in method: enable Anonymous (and Email/Password to link devices).

    3. Firestore Database: create a database, then set these rules.

    rules_version = '2';
service cloud.firestore {
  match /databases/{db}/documents {
    match /users/{uid} {
      allow read, write: if request.auth != null
                         && request.auth.uid == uid;
    }
  }
}

    4. Host this file on https (GitHub Pages, Netlify, localhost) and add that domain under Authentication > Settings > Authorized domains.

    Everything is stored in one document per user, /users/{uid} (1 MiB limit, roughly 700 cards).
